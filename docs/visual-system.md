# 文学编辑插画视觉系统

默认风格是“现代文学编辑插画动态短片”。它更接近高级书籍插画、文学杂志和动态书封，不使用传统儿童火柴人，也不默认做写实 AI 微电影。

## 账号级统一感

统一的是干净二维线稿、分离平涂色块、高对比、大留白、手机端可读构图，以及克制的电影镜头语言。

## 每本书必须重新设计

每本书确定四件事：主背景或环境气质，最多三种强调色，三到五个专属意象，一个独特构图或环境特征。

至少一个意象在三段或更多片段中重复出现，形成整条视频的视觉记忆。

## 人物

人物保持年龄合适的简化比例，可以有外套、帽子、裙装、制服等轮廓。五官高度简化，优先保证跨片段一致性。

## 大型元素

月亮、太阳、海洋、建筑、动物和植物都必须与人物使用同一插画语言。避免平面人物突然配摄影月球、写实动物、图库海滩或高光 3D 道具。

## 色彩

颜色保持干净、清透、边界明确。默认避免灰褐滤镜、脏纸颗粒、套色偏移、重度复古磨损和颜色互相污染。

## 动效

每两到三秒发生一次与故事有关的变化。可以使用人物动作、环境变化、物件交互、推镜、跟拍、视差、前景擦拭、形状变形和 Match Cut。

动画必须帮助叙事，不能变成纯 Motion Graphic 展示。
